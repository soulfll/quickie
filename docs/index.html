Your most-used apps, one press away.

Quickie is a compact key pad for Windows 11. Give each key a job — open your work apps, jump to a site, type a snippet, or replay a set of keystrokes — then do it all with a single press.

Quickie

Set up in three steps

The keys work as soon as you plug it in. The app is what turns them into your shortcuts.

  1. Install the app

    Download the installer, accept the short privacy notice, and click through. There’s nothing else to install.

  2. Plug in your Quickie

    Use any USB port. It shows up as a keyboard, so there are no drivers to hunt for.

  3. Give each key a job

    In the app, choose “Assign via Key Press,” press the key you want, pick what it should do, then press it once more to confirm.

One key, as many things as you like

Stack several actions on a key and they run in order. Pressing it is always a single press, however much is behind it.

Profiles

  • Make a separate set of key assignments for each kind of work.
  • Switch profiles in the app and the whole pad changes with it.

Built for confirming, not guessing

  • Assigning is a deliberate press-select, press-confirm.
  • Press a different key instead and nothing gets saved.

Private by design

The app works entirely on your computer.

What it does

  • Listens for a small set of dedicated codes sent by your Quickie — codes no normal shortcut uses.
  • Runs what you assigned: opens an app, opens a site, types your snippet, or replays your recording.
  • Saves your assignments in a file on your own computer.

What it doesn’t

  • It doesn’t send anything over the internet — no analytics, no telemetry, no server.
  • It doesn’t read your regular typing. The one exception is when you choose to record keystrokes: it captures keys only from Start until you click Stop, and keeps them only on your computer.

Questions

Does it work on Mac or Linux?

Quickie is built for Windows 11. The keys will still register as keyboard presses elsewhere, but the app is a Windows app.

Do I need to be online?

Only to download the installer. After that the app doesn’t need a connection, and it never sends your data anywhere.

Will Windows warn me when I install it?

Possibly. New installers that aren’t digitally signed can trigger a blue “Windows protected your PC” screen. Choose “More info,” then “Run anyway.”

Why does the app ask for permission to watch the keyboard?

Windows requires it for any app that reacts to a key press while another program is in front — the same permission window-snapping tools and macro pads use.

Can one key do more than one thing?

Yes. Add as many actions as you like to a key — apps, websites, text and recordings can be mixed — and they run in order when you press it.
